Property Comparator — first-time setup

What is this?

This tool stores your property data in a private GitHub repository under your account. To read and write to that repo, the tool needs a personal access token (PAT) — think of it like a password that only works for one specific repo.

Your PAT is stored in your browser only. It's never sent anywhere except to GitHub. You can revoke it any time from your GitHub settings.

Generate a Personal Access Token

  1. Open the GitHub PAT page (link below).
  2. Under Repository access, choose Only select repositories and pick opoo-em/property-tool-private.
  3. Under Repository permissions, set Contents to Read and write.
  4. Set Expiration to one year (or "no expiration" if you prefer).
  5. Copy the token when GitHub shows it — it won't be visible again.

Open GitHub PAT creation →

Paste and test

Paste the token you just generated. The tool will make one read call against your private repo to confirm the token works.
