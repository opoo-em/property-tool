Install: Add to Property Tool

A bookmark you click while on a Zillow listing. It reads what it can from the page, opens the Property Tool in a new tab, and pre-fills the Add Property form so you only have to review and Save.

Step 1 — Show your bookmarks bar

  • Chrome / Edge: Ctrl+Shift+B (Mac: ⌘+Shift+B)
  • Firefox: Right-click empty area near the tabs → Bookmarks Toolbar → Always Show
  • Safari: View menu → Show Favorites Bar

Step 2 — Drag this button up to your bookmarks bar

Add to Property Tool

If dragging doesn't work in your browser, right-click the button → Bookmark link… (or "Add to bookmarks") and save it to your bookmarks bar.

Loading the bookmarklet…

Step 3 — Use it

  1. Open any Zillow listing page (a /homedetails/… URL).
  2. Click the Add to Property Tool bookmark in your bar.
  3. A new tab opens the Property Tool at Add Property, with the fields it could read from the listing already filled in. Review, tweak, hit Save.

What it fills in

  • Basics: address, city, state, listing URL, property type, latitude/longitude (which becomes the map pin)
  • Financial: price, monthly HOA fee
  • Physical: beds, baths, square feet, year built

Nickname is seeded from the street address so Save works right away — rename it to whatever's easier to remember. Everything gut-check, commute time, and hard-filter is still up to you.

What can go wrong

  • Some fields come out blank. Zillow changes their page shape now and then. Fill the missing ones in manually and let Aly know — the bookmarklet's extractor can be updated.
  • New tab is blocked. Allow pop-ups from zillow.com, or click the notification in the address bar.
  • You're not signed in to the app. The bookmarklet opens the app in a new tab. If it's your first time on that browser, the setup wizard runs first — finish it, then click the bookmarklet again.
  • It only works on listing pages. Search results, saved-home lists, and rental pages don't have a single property to extract — nothing will pre-fill.

Bookmarklet source: zillow-extract.js. Runs entirely on the Zillow tab in your own browser — never sends listing data anywhere except into your own Property Tool tab.
